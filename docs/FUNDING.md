# Funding and GitHub Sponsors

The project is intended to accept optional community support for maintenance, bug fixes, compatibility work, documentation, and new features.

## Personal-account setup

1. Apply for GitHub Sponsors from your personal GitHub account.
2. Complete the profile and sponsorship tiers.
3. Submit the required bank and tax information and enable two-factor authentication.
4. Wait for GitHub's approval.
5. Copy `.github/FUNDING.yml.example` to `.github/FUNDING.yml`.
6. Replace the placeholder with your real GitHub Sponsors username.
7. Enable the repository Sponsorships feature in repository settings.

GitHub's supported-regions list currently includes India, but approval and payment setup are still required. Check the current official documentation before relying on availability:
- [About GitHub Sponsors](https://docs.github.com/en/sponsors/getting-started-with-github-sponsors/about-github-sponsors)
- [Set up GitHub Sponsors for a personal account](https://docs.github.com/en/sponsors/receiving-sponsorships-through-github-sponsors/setting-up-github-sponsors-for-your-personal-account)
- [Display a Sponsor button](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/displaying-a-sponsor-button-in-your-repository)

## Transparency

Explain what sponsorship supports. Sponsorship is optional and does not buy creator endorsement, exclusive access, ownership, or a guaranteed feature. Do not promise a donation target or a specific star count.

Do not add an active `FUNDING.yml` until your own personal funding profile and URL are ready.
