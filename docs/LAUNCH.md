# Community launch plan

The repository should be the source of truth. Publish the code, documentation, real screenshots, and a working installation path before promoting it.

## 1. GitHub repository
- Publish from the maintainer's personal GitHub account.
- Use a concise description and relevant topics (for example: `react`, `threejs`, `tauri`, `ai-assistant`, `minecraft` only where permitted by the platform and project rules).
- Add the README, docs, asset credits, contribution guide, security policy, and a clear licence for original code after rights review.
- Create a GitHub Release only after the Windows installer has been installed and tested.
- Add funding links only after the personal funding account is approved and the real URL is known.

## 2. Dev.to article
Write a technical build story, not just an advertisement. Explain:
- Why the project exists.
- How the React / Three.js / Node / Tauri architecture fits together.
- How the character rig, gestures, equipment attachments, local memory, and speech queue work.
- What was difficult, what remains limited, and how developers can contribute.
- Link to the GitHub repository and current demo.

## 3. Reddit
- Choose communities where Minecraft, Unstable SMP fan projects, Three.js, Tauri, or indie development posts are relevant.
- Read each subreddit's current rules before posting; some communities ban project promotion or require a particular weekly thread/flair.
- Be transparent that this is your own project.
- Do not mass-post identical promotional copy across many subreddits. Participate in discussions and share technical detail that is genuinely useful to each community.

## 4. X
Use a short clip or GIF of the real app, one clear sentence about what it does, a link to the repository, and an invitation for feedback/contributions. Avoid claiming creator endorsement or implying the creator is involved.

## 5. Measure useful outcomes
Track successful installs, reproducible issues, contributor activity, documentation gaps, and returning users. Stars are useful visibility, but they are not a substitute for a healthy user and contributor community.
