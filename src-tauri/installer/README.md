# Installer branding assets

These assets brand the native installers for Wemmbu AI Assistant 0.2.9.

- `../icons/icon.png` is the square pixel-art avatar used as the source for Tauri platform icons.
- `../icons/icon.ico` is generated by `cargo tauri icon` and is used for the Windows setup and uninstaller icons.
- `nsis-header.bmp` is the 150x57 NSIS wizard header.
- `nsis-sidebar.bmp` is the 164x314 NSIS Welcome/Finish panel.
- `dmg-background.png` is the background for the macOS DMG window.
- `wemmbu-logo.png` is the shared transparent avatar mark.

The NSIS installer displays the repository's GPL-3.0 license from `../LICENSE`. Linux packages use the generated Tauri PNG icons and package metadata.
