# Public release checklist

Before publishing this project or redistributing any installer, confirm the following items.

- [ ] Confirm permission or a redistributable licence for all armour GLBs.
- [ ] Confirm the source and redistribution permission for the Wemmbu logo and any other public-facing artwork.
- [ ] Preserve attribution notices for all CC BY 4.0 models and modified assets.
- [ ] Verify that any external voice or reference ID is approved for public release and is not creator-specific unless explicitly permitted.
- [ ] Check the repository history for private keys, API keys, local data, memory databases, session files, or other personal material before publishing.
- [ ] Review dependency licences and include any notices required by third-party components.
- [ ] Ensure the software licence and asset rights are reviewed before shipping public builds or public installers.

## Required review notes

The project includes GLB asset files for the character armour, logo artwork, and associated 3D content. The public release should not proceed until the rights for each asset are confirmed and documented.

This checklist must be completed before any public repository publication, open-source release, or distributed installer is published.
